# FOMO Copy Desk (PAPER)

Public static shell for the FOMO Copy Desk phone app. This repository holds
**only** the web app (HTML, CSS, JS, icons, manifest, and service worker).

It does not contain trading data, a database, logs, API keys, or tokens.

This is a PAPER-mode dashboard. It never places live trades and never
withdraws funds.

## Open it

After GitHub Pages is enabled, the app is at:

https://anthonytrjr.github.io/copy-desk/

## On an iPhone

1. Open that URL in Safari.
2. Tap Share, then Add to Home Screen.
3. Open the app from the home screen and paste your secret data link when
   asked. The link stays on the phone. It is not stored in this repository.

The data link is unlisted, not access-controlled. Anyone who has it can read
the paper dashboard.
